The app has a coherent dark design system in `frontend/src/styles.css` (`:root` tokens, shared `.btn` / `.badge` / `.card` / `.modal` / sidebar layout) and reusable primitives in `frontend/src/components/ui.tsx`. Hierarchy, semantic status colors, and table/form patterns are generally consistent. Gaps are concentrated in mobile sidebar behavior, modal keyboard/focus behavior, destructive-action visual language, motion/`prefers-reduced-motion`, and incomplete spacing/focus tokens—not in wholesale visual chaos.

## Audit Scope and Methodology

- **Scope:** Authenticated shell (`Layout`), login/setup, Dashboard through Settings, shared UI primitives, and `frontend/src/styles.css` (sole stylesheet).
- **Method:** Code and stylesheet review against the UI checklist; contrast ratios estimated for token pairs (WCAG 2.1 AA); findings tied to real selectors/components only.
- **Rules referenced:** 15-ui-audit skill (CHECKLIST, SEVERITY_GUIDELINES, REPORT_TEMPLATE).
- **Areas covered:** Modernity/consistency, spacing, navigation/sidebar/topbar, buttons/badges/chips, forms, cards/modals, tables, loaders/feedback, colors/contrast/typography, whitespace/minimalism, animation, patterns.

## Strengths (observed)

- Unified dark palette with semantic severity colors (`--high` / `--medium` / `--ok` / `--accent`) used by badges, alerts, and banners.
- Clear component roles: primary / ghost / danger / warn buttons; status badges with text labels (not color alone).
- Tables: sticky headers, hover, `.table-wrap` horizontal scroll, empty/loading patterns via `Empty` / `Loading`.
- Forms: top labels (`.field`), hints, focus ring on inputs, shared `.form-grid`.
- Modals scroll (`max-height: 90vh; overflow: auto`) with sticky header—content not clipped by fixed height.
- Soft dark surfaces (`--bg` / `--panel*`) keep chrome quiet relative to content; accent reserved for interactive emphasis.

## Recommendations

1. Fix **destructive styling** and **setup step contrast** first—both are high-visibility trust/readability issues with small diffs.
2. Bring **Modal** in line with Lightbox keyboard behavior (Escape, focus) so overlays feel like one system.
3. Treat **≤900px layout** as a first-class shell: drawer nav beats stacking the full sidebar.
4. Formalize tokens (`--space-*`, `--radius-*`, `--focus-ring`, `--accent-ink`) to reduce inline styles and drift.
5. Preserve the existing dark, token-driven look; prefer tightening consistency over a redesign.
